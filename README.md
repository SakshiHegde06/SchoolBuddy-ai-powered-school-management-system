# SCHOOLBUDDY 🎓

SCHOOLBUDDY is a full-stack AI-powered school management system designed to simplify and digitize communication and academic management between administrators, teachers, students, and parents.

The platform provides dedicated dashboards for different users, allowing administrators to manage school data, teachers to handle academic activities, students to track their performance, and parents to monitor attendance and progress.

Built using modern technologies like React, Spring Boot, MongoDB, and AI-based features, SCHOOLBUDDY aims to create a smarter, more efficient, and connected educational ecosystem.

## Key Features 🚀

- 👨‍💼 **Admin Dashboard**
  - Manage students, teachers, classes, and subjects
  - Assign teachers to subjects and classes
  - Publish announcements and events

- 👩‍🏫 **Teacher Dashboard**
  - View assigned classes and subjects
  - Upload marks and attendance
  - Add student remarks
  - Share homework and academic updates

- 👨‍👩‍👧 **Parent Dashboard**
  - Monitor attendance
  - View academic performance
  - Track student progress and improvements

- 🎓 **Student Dashboard**
  - View personal academic information
  - Access marks, attendance, homework, and remarks

- 🤖 **AI-Powered Features**
  - Smart timetable generation without teacher/class conflicts
  - Student performance analysis
  - Risk prediction and improvement suggestions based on academic history

## Goal 🎯

The goal of SCHOOLBUDDY is to reduce manual effort in school administration and provide an intelligent platform that improves interaction, transparency, and decision-making between schools, teachers, students, and parents.
